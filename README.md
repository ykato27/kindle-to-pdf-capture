# Kindle自動スクリーンショット＆PDF化システム

Kindle アプリ（Mac の Amazon Kindle、Windows の Kindle for PC）で開いている電子書籍を、1ページずつスクリーンショットして1冊分の PDF にまとめる Python ツールです。同じ画面が3回続いたら本の終わりとみなして自動で止まり、途中で止めたときもそこまでのページで PDF を作ります。

## セットアップ

```bash
uv sync
```

Mac では、このツールを動かすターミナル（ターミナル.app、iTerm、VS Code など）に次の許可が要ります。「システム設定 > プライバシーとセキュリティ」で追加してください。

| 許可 | 使う機能 | 無いとどうなるか |
| --- | --- | --- |
| 画面収録 | スクリーンショット | Kindle の画面が写らない |
| アクセシビリティ | ページ送りのキー入力・クリック | ページが進まず、同じ画面が3回続いてすぐ止まる |
| 入力監視 | Esc キーでの停止 | Esc が効かない（マウスを画面の角へ動かす方法は使える） |

## 使い方

1. Kindle で本を開き、最初のページを表示しておきます。全画面表示にすると余白を切り落とせて PDF が小さくなります。上部のツールバーが出ていたら消しておいてください（出たままだと、最初のキーがツールバーを消すだけに使われ、1枚目がツールバー付きになります）。
2. 次を実行し、質問に答えます。何も入れずに Enter を押すと［］内の値になります。

```bash
uv run python -m kindle_capture
```

| 質問 | 説明 |
| --- | --- |
| 書籍名 | 保存フォルダと PDF の名前 |
| 最大ページ数 | 撮影する上限。本の終わりは自動で検出するので、多めでよい |
| ページを進める向き | R=右（横書きの本）、L=左（縦書きの本） |
| ページ送りの方法 | K=矢印キー（通常はこちら）、C=画面の端をクリック（キーが効かないとき） |
| 待ち秒数 | 撮影してからページを送るまで・ページを送ってから撮影するまでの秒数 |
| PDF の画質 | S=標準、L=軽量、H=高画質（撮影した解像度のまま。容量は標準の約3倍） |

3. Mac では Kindle が自動で前面に出ます（Windows では3秒以内に Kindle を前面にしてください）。撮影が始まったら、終わるまでキーボードとマウスに触らないでください。

画像と PDF は `~/kindle_capture/<書籍名>/` に保存されます。同じ書籍名で撮り直すと、前回の画像は消えます。

## 止め方

- **Esc キー**：Kindle を前面にしたまま押せば止まります。
- **別のアプリに切り替える**（Mac のみ）：Kindle が前面でなくなると、ほかのアプリにキーを送らないよう止まります。通知などで別のアプリが前面に出たときも止まります。
- **マウスを画面の角へ動かす**：Esc が効かないときの予備です。
- **自動停止**：同じ画面が3回続くと止まります。最初のページから進まずに止まったときは、ページを進める向き（R/L）を逆にしてください。

どの止め方でも、撮影済みのページで PDF を作ります。

## 開発

```bash
uv run pytest
```

実際の撮影画像で自動停止の判定を確かめるテストは、画像のあるフォルダを `KINDLE_CAPTURE_REPLAY_DIR` に指定したときだけ動きます（市販の書籍が写るため、画像はリポジトリに入れません）。
