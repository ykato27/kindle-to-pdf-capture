# Kindle自動スクリーンショット＆PDF化システム

Kindle アプリ（Mac の Amazon Kindle、Windows の Kindle for PC）で開いている電子書籍を、1ページずつスクリーンショットして1冊分の PDF にまとめる Python ツールです。同じ画面が3回続いたら本の終わりとみなして自動で止まり、途中で止めたときもそこまでのページで PDF を作ります。

## セットアップ

```bash
uv sync
```

Mac では、このツールを動かすターミナル（ターミナル.app、iTerm、VS Code など）に次の許可が要ります。足りないときは撮影の前に macOS の確認画面と案内が出るので、「システム設定 > プライバシーとセキュリティ」で許可し（一覧に無ければ＋で追加し）、ターミナルを開き直してください。前回の画像から PDF だけを作り直すときは、許可は要りません。

| 許可 | 使う機能 | 無いとどうなるか |
| --- | --- | --- |
| 画面収録 | スクリーンショット | 起動時に案内を出して終わる |
| アクセシビリティ | ページ送りのキー入力・クリック | 起動時に案内を出して終わる |
| 入力監視 | Esc キーでの停止 | Esc だけが効かない（別のアプリへの切り替えや、マウスを画面の角へ動かす方法は使える） |

## 使い方

1. Kindle で本を開き、最初のページを表示しておきます。上部のツールバーが出ていたら消しておいてください（出たままだと、最初のキーがツールバーを消すだけに使われ、1枚目がツールバー付きになります）。
2. 次を実行し、質問に答えます。何も入れずに Enter を押すと［］内の値になります。

```bash
uv run python -m kindle_capture
```

| 質問 | 説明 |
| --- | --- |
| 書籍名 | 保存フォルダと PDF の名前 |
| 最大ページ数 | 撮影する上限（9999まで）。本の終わりは自動で検出するので、多めでよい |
| ページを進める向き | R=右（横書きの本）、L=左（縦書きの本） |
| ページ送りの方法 | K=矢印キー（通常はこちら）、C=画面の端をクリック（キーが効かないとき） |
| 待ち秒数 | 撮影してからページを送るまで・ページを送ってから撮影するまでの秒数 |
| PDF の画質 | S=標準（高さ1200px）、L=軽量（高さ900px）、H=高画質（撮影した解像度のまま。容量は標準の約3倍） |

3. Mac では Kindle が自動で前面に出ます（Windows では3秒以内に Kindle を前面にしてください）。撮影が始まったら、終わるまでキーボードとマウスに触らないでください。

Mac では Kindle のウィンドウだけを撮るので、ほかのウィンドウやメニューバーは写りません。Kindle を外部ディスプレイに置いても撮れます。Windows では主ディスプレイ全体を撮ります。

画像と PDF は `~/kindle_capture/<書籍名>/` に保存されます。同じ書籍名で起動すると、前回の画像から PDF だけを作り直すか（画質を変えたいとき）、消して撮り直すかを選べます。

## 止め方

- **Esc キー**：Kindle を前面にしたまま押せば止まります。
- **別のアプリに切り替える**（Mac のみ）：Kindle が前面でなくなると、ほかのアプリにキーを送らないよう止まります。通知などで別のアプリが前面に出たときも止まります。
- **マウスを画面の角へ動かす**：Esc が効かないときの予備です。
- **自動停止**：同じ画面が3回続くと止まります。最初のページから進まずに止まったときは、ページを進める向き（R/L）を逆にしてください。

どの止め方でも、撮影済みのページで PDF を作ります。

## 制約

- 白紙のページが3枚以上続く本では、そこを本の終わりとみなして止まります。続きは、そのページを開いて別の書籍名で撮影してください。
- 画面の端をクリックする方式（C）で押す位置と、マウスを角へ動かして止める方法は、主ディスプレイを前提にしています。外部ディスプレイではキー方式（K）と Esc を使ってください。
- Windows では、Kindle が前面かどうかの確認とウィンドウだけの撮影を行いません。撮影中にほかのアプリへ切り替えないでください。

## 開発

```bash
uv run pytest
```

実際の撮影画像で自動停止の判定を確かめるテストは、画像のあるフォルダを `KINDLE_CAPTURE_REPLAY_DIR` に指定したときだけ動きます（市販の書籍が写るため、画像はリポジトリに入れません）。
